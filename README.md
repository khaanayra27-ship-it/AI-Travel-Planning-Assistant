# AI-Travel-Planning-Assistant
The application provides AI-driven destination recommendations, hotel and attraction suggestions, budget management, packing checklists, weather insights, and an intelligent chatbot that answers travel-related questions in real time. Users can save and manage their travel plans through a simple and user-friendly interface.
## Features

- AI-powered travel itinerary generation
- Destination recommendations
- Hotel suggestions
- Budget and expense planning
- Smart packing checklist
- Destination information and travel tips
- User authentication
- Responsive user interface
- Fast and interactive experience

## Installation Steps

### 1. Clone the Repository

```bash
git clone https://github.com/AiraSalman/AI-Travel-Planning-Assistant.git
```

### 2. Move into the Project Folder

```bash
cd AI-Travel-Planning-Assistant
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the `backend` folder and add:

```env
MONGODB_URI=your_mongodb_connection
OPENAI_API_KEY=your_openai_api_key
JWT_SECRET=your_secret_key
PORT=5000
```

### 5. Start the Backend Server

```bash
npm start
```

### 6. Install Frontend Dependencies

Open a new terminal and run:

```bash
cd frontend
npm install
```

### 7. Start the Frontend

```bash
npm run dev
```

The frontend will usually be available at:

```
http://localhost:5173
```
